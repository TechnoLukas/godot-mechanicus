# About Godot Mechanicus

### Description

Godot. Jolt. Demos based on new godots physics update with JoltPhysics. Different mechanisms, vehicles, a lot of cool stuff.

### Why this name?

There is a "Adeptus Mechanicus" faction in (my favourite) tabletop game, called Warhammer 40,000. The whole faction vibe is: "Cult of the Machine based on Mars which provides the Imperium with its scientists, engineers and technicians." So I thought it would it be really cool to link the idea to godot, because I plan to work on a lot of cool mechanisms, vehicles, mechanical thing, etc. 

Godot + Adeptus Mechanicus = Godot Mechanicus
